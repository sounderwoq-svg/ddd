# Разведка

Результаты разведки сохраняются в `recon/<target>/`:

- `whois.txt` — информация о домене и владельце
- `dns_*.txt` — DNS записи (A, MX, TXT, NS)
- `subdomains.txt` — найденные поддомены
- `whatweb.txt` — технологический стек
- `waf.txt` — определение WAF
- `headers.txt` — HTTP заголовки
- `robots.txt` — файл robots.txt
- `sitemap.xml` — карта сайта
- `sslscan.txt` — аудит SSL/TLS
- `cert.txt` — сертификат
- `wayback_urls.txt` — исторические URL из Wayback Machine
