# Pentest: nskavtovokzal.ru

**Цель:** https://nskavtovokzal.ru  
**Срок:** 3 дня  
**Тип:** Белый ящик (с разрешения владельца)

## Структура проекта

```
├── recon/          # Разведка (пассивная + активная)
├── scanning/       # Сканирование уязвимостей
├── exploitation/   # Эксплуатация и PoC
├── reporting/      # Отчёты
└── scripts/        # Автоматизация
```

## Методология

**День 1** — Разведка и сканирование  
**День 2** — Эксплуатация уязвимостей  
**День 3** — Документирование и финальный отчёт

## Запуск

```bash
# Полный автоматизированный прогон
bash scripts/run_all.sh nskavtovokzal.ru

# Только разведка
bash scripts/01_recon.sh nskavtovokzal.ru

# Только сканирование
bash scripts/02_scan.sh nskavtovokzal.ru
```

## Инструменты

| Инструмент | Назначение |
|-----------|-----------|
| nmap | Сканирование портов и сервисов |
| nikto | Сканирование веб-уязвимостей |
| gobuster | Перебор директорий/файлов |
| sqlmap | SQL-инъекции |
| whatweb | Определение технологий |
| wafw00f | Определение WAF |
| sslscan | Аудит SSL/TLS |
| curl | Ручные HTTP-запросы |
| subfinder | Поиск поддоменов |
| nuclei | Сканирование по шаблонам CVE |
